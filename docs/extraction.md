# Extracting FF5_MESS.BIN

1. Create a disc image from your copy of Final Fantasy V for PlayStation.

2. Open the image with a tool capable of viewing PlayStation data tracks.

3. Navigate to:

   ```
   NAR/FF5_MESS.BIN
   ```

4. Extract the file.

This file contains the game's script data and dialogue-related control codes (the waits in the opening cinematic and item/cost variables.)
